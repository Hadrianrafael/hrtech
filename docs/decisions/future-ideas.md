# Ideias Futuras — HR Tech

Este documento registra ideias levantadas durante o desenvolvimento que **não** fazem parte do escopo atual. Existe para que essas ideias não se percam em conversas, sem comprometer a arquitetura atual com implementação prematura (ver `architecture.md` → "Princípio de escopo"). Nenhum item aqui tem prioridade, prazo ou compromisso associado.

- Integração com WhatsApp (atendimento, notificações)
- Agentes de IA (atendimento automatizado, geração de conteúdo, automação interna)
- Marketplace de integrações entre as plataformas SaaS
- CRM interno da HR Tech
- ERP interno
- Chat interno entre equipe/clientes
- Aplicativo mobile (uma ou mais verticais)
- Portal do Cliente unificado (acesso a todas as SaaS contratadas em um só lugar)

## Como uma ideia sai daqui

Quando uma ideia deste documento ganha um caso de uso concreto e vira decisão:
- Se for produto ou fase da empresa → vira entrada em `docs/roadmap.md`
- Se for decisão técnica ou arquitetural → vira um novo ADR em `docs/adr/`

Ela é removida deste documento no mesmo commit em que a entrada correspondente é criada.
